## Description
This project demonstrates HTML forms, CSS styling with custom soft pink theme, Bootstrap 5 integration, and Javascript form validation.

## Structure
- `index.html`: Part 1 - Basic Contact Form with HTML5 Validation.
- `bootstrap.html`: Part 2 - Bootstrap Form styling & validation classes.
- `registration.html`: Part 3 - Advanced Registration Form.
- `style.css`: Soft pink glassmorphism custom styles.
- `validate.js`: Custom JS validation logic.
- `bg.js`: UI visual entrance transitions.

## How to Run
Open `index.html` in any web browser or deploy directly to GitHub Pages / Netlify.
